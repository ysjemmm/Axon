# 文档生成（Document Forge）

用户要"把这份数据做成 Excel""生成一个 Word 文档""导出成 PDF"时，使用本能力包。

## 覆盖范围
- Excel（.xlsx）/ CSV
- Word（.docx）
- PDF

## 工作流程
1. **先问清三件事**（缺一不可，不要自行假设）：
   - 内容从哪来：用户直接给的数据 / 工作区里的某个文件 / 需要你整理归纳
   - 要什么格式：Excel / Word / PDF
   - 放哪里：用户指定路径，或按下方约定
2. 读取对应技能的 SKILL.md（路径在 activate_power 的返回里）拿具体做法与模板 —— excel / word / pdf。
3. 生成。
4. **验证**：确认文件确实存在且大小 > 0；要如实报告，不要假定成功。
5. 回复里给出**绝对路径** + 内容结构简述。

## 输出位置约定
- 用户给了路径 → 用用户的
- 没给 → 主工作区的 `output/` 目录下（不存在就创建）
- 始终使用绝对路径

## 纪律
- 只为生成文档而工作，不要顺手改用户的项目源码。
- 缺依赖时先装；装不上要如实说明缺什么，不要伪造"已生成"。
- 路径含空格或中文时要正确加引号。
