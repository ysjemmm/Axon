# Axon

Axon 是集智能对话、代码开发与文档协作于一体的 AI 工作台。产品以 IDE 工作界面提供统一入口，基于同一套 Agent 内核，在不同工作场景中调用模型与本地工具完成任务。

## 工作场景

- **Chat · 智能对话**：面向提问、方案讨论和信息整理，支持多轮会话与历史记录。
- **Code · 开发协作**：结合编辑器与项目上下文，支持代码检索、文件修改、命令执行、浏览器验证和内联补全。
- **Cowork · 文档协作**：面向 Excel、Word、PDF、CSV 等办公文件，支持选择本地文件、指定产出位置、查看任务进展与预览结果；会话历史与开发场景分开管理。文档处理能力通过可启用的能力包扩展。

## 核心能力

- **模型接入**：配置 Provider 和模型，支持 OpenAI 兼容接口及 Anthropic Messages 协议。
- **任务执行**：Agent 按需读取文件、搜索内容、调用工具并返回结果；长任务可使用分阶段工作流。
- **安全与扩展**：提供命令确认和信任规则，并可通过 Skill、Power、MCP 扩展能力。

## 技术组成

项目由 VS Code 扩展、React 工作界面、TypeScript Agent 核心和运行时服务组成。源码构建要求 Node.js 20+、pnpm 9：

```bash
pnpm install
pnpm build
```
